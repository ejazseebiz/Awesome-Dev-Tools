# Contributing to Awesome Dev Tools

Thanks for your interest in improving this repository.

## How to contribute

You can help in several ways:

- suggest a new tool or resource
- add a missing category or subcategory
- improve the documentation
- report broken or outdated links
- refine the README structure for readability

## Contribution guidelines

Before submitting a suggestion, make sure it is:

- genuinely useful for developers, designers, or product builders
- relevant to the category or section it belongs to
- actively maintained or widely trusted
- safe and accessible to use

## Submission checklist

When proposing a new tool, include:

- tool name
- official website or repo URL
- short description
- category
- pricing model (free, freemium, paid)
- why it is valuable for developers or designers

## Pull request process

1. Fork the repository.
2. Create a branch for your change.
3. Update the README or add a resource in the appropriate section.
4. Ensure the content is clear, accurate, and properly formatted.
5. Open a pull request with a clear title and description.

## Issue suggestions

Use the issue templates for:

- tool suggestions
- broken links or outdated entries
- documentation improvements
- enhancements to the repository structure

Thank you for helping make this repository more useful and more discoverable.
